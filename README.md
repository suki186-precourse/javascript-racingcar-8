## 🪐 [Precourse 2주차] 자동차 경주

초간단 자동차 경주 게임을 구현한다.

> indent(인덴트, 들여쓰기) depth는 최대 2까지.
> 3항 연산자 쓰지 않기.
> 함수는 한 가지 일만 하도록 최대한 작게.

---

### ✨ 구현할 기능 목록

**🔹 기본 기능**

1. 자동차 이름 입력 처리

- [ ] n대의 자동차 이름 입력 받기
- [ ] 입력받은 문자열을 구분자(,) 기준으로 분리 → 리스트로 반환
- [ ] 불필요한 공백 제거
- [ ] Car 객체 배열 생성

2. 시도 횟수 입력 처리

- [ ] 시도 횟수 입력 받기
- [ ] 입력값을 정수로 변환

3. 자동차 이동 로직

- [ ] 0~9 사이의 랜덤 숫자 생성 함수 구현
- [ ] 랜덤 숫자가 4이상일 때 전진
- [ ] 자동차 이동거리(-) 저장 → 문자열(name : ---)로 반환

4. 경주 진행 상황 출력

- [ ] 시도 횟수만큼 경주 반복
- [ ] 각 시도마다 자동차 이동, 결과 출력

5. 최종 우승자 판별 및 출력

- [ ] 자동차별 총 이동거리 계산
- [ ] 가장 많이 이동한 자동차의 이름 추출
- [ ] 최종 우승자 문구 출력(최종 우승자 : name) → 여러 명이면 쉼표(,)로 연결

**🔹 예외 처리**

1. 자동차 이름 유효성 검증

- [ ] 이름이 5자를 초과한 경우 → Error
- [ ] 이름이 비어 있는 경우(공백만 있는 경우 포함) → Error
- [ ] 중복된 이름이 있는 경우 → Error

2. 이름 구분자(,) 형식 검증

- [ ] 쉼표 사이에 값이 없는 경우(연속 구분자) → Error
- [ ] 쉼표 말고 다른 구분자를 사용한 경우 → Error

3. 시도 횟수 입력값 검증

- [ ] 숫자가 아니거나 정수가 아닌 경우 → Error
- [ ] 1미만이거나 공백인 경우 → Error

**🔹 테스트 코드**

- [ ] Jest를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트

### 📁 src 디렉토리 구조

```bash
src/

├── index.js
├── domain/

│   ├── validators.js   # 입력값, 구분자 검증

├── view/
│   ├── InputView.js    # 입력
│   └── OutputView.js   # 출력
└── constants.js        # 상수 파일

```
