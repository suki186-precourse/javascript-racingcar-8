## 🪐 [Precourse 2] 자동차 경주

초간단 자동차 경주 게임을 구현한다.

> indent(인덴트, 들여쓰기) depth는 최대 2까지.
> 3항 연산자 쓰지 않기.
> 함수는 한 가지 일만 하도록 최대한 작게.

---

### ✨ 구현할 기능 목록

**🔹 기본 기능**

1. 자동차 이름 입력

- [ ] ,로 구분된 자동차 리스트 입력 받기
- [ ] , 기준으로 분리 -> 이름 앞 뒤 공백 제거
- [ ] 자동차 이름을 리스트로 반환

2. 이동 횟수 입력

- [ ] 반복할 횟수 입력 받기
- [ ] 입력 값을 정수로 변환

3. 자동차 이동

- [ ] 0~9 사이의 랜덤값 생성 함수 구현
- [ ] 랜덤 숫자가 4 이상이면 전진
- [ ] 자동차 현재 위치 저장

4. 경주 진행

- [ ] 이동 횟수만큼 반복
- [ ] 각 차수별 이동 현황 출력

5. 최종 우승자 판별

- [ ] 자동차별 현재 위치 비교
- [ ] 현재 위치가 가장 큰 자동차 이름 반환
- [ ] 최종 우승자 출력

**🔹 예외 처리**

1. 자동차 이름 유효성 검사

- [ ] 길이가 5자를 초과한 경우
- [ ] 이름이 공백인 경우
- [ ] 중복된 이름이 있는 경우
- [ ] 자동차가 2개 미만인 경우

2. 이동 횟수 유효성 검사

- [ ] 정수가 아닌 경우
- [ ] 1미만인 정수인 경우

3. 구분자 유효성 검사

- [ ] ,가 아닌 다른 구분자를 사용한 경우
